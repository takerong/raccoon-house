이 집 너구리 미쳤나 봐 — Cloudflare 업로드용 완성본

1. 이 ZIP은 미리 빌드한 정적 홈페이지입니다. index.html과 assets/, static/ 폴더를 함께 업로드하세요.
2. Cloudflare Pages: Workers & Pages → Create application → Pages → Direct Upload 계열 메뉴 → 프로젝트 이름 입력 → 이 ZIP 또는 압축을 푼 폴더 업로드 → Deploy. 화면에 따라 메뉴 이름은 달라질 수 있습니다.
3. Workers의 정적 파일 업로드 화면이 있다면 같은 파일을 사용할 수 있습니다. CLI를 쓴다면 압축을 푼 폴더에서 npx wrangler deploy --config wrangler.jsonc 를 실행하세요. 계정 로그인 필요. 기존 프로젝트와 겹치지 않는 name을 선택하세요.
4. Git 연결 빌드를 만드는 자료가 아니라, 완성된 정적 파일을 직접 업로드하는 자료입니다. dashboard 업로드에는 빌드 명령이 필요 없습니다.
5. index.html이 압축 최상위에 있습니다. index.html 하나만 업로드하면 사진과 음악이 누락됩니다.

포함 기능
원본 배너, 아이보리+브라운 발바닥 배경, 상세 프로필, 서로 다른 집 구조, 클릭형 동네 지도, 가상 폰의 일정·앨범·채팅·메모·공동 SNS, 하이라이트·선택형 댓글, 주변 NPC 11명 소개·게시물별 NPC 댓글, 숨은 너굴이 찾기, 피해 장부, 관계 모드 안내, 스포일러 봉투.

BGM
최신 이 집 너구리.mp3를 theme-v2.mp3로 포함했습니다. 페이지를 열면 기본 ON으로 재생을 시도합니다. 브라우저 제한 시 첫 터치·클릭·키 입력에서 재시도합니다. 끄기는 현재 페이지에서 유지되며 페이지를 새로 열면 기본 ON으로 돌아갑니다.

진행 기록
흔적 찾기·장부·SNS 좋아요/저장·선택형 댓글은 방문자의 브라우저 로컬 저장입니다. 채팅은 페이지 안에서만 유지됩니다. 다른 기기·브라우저·도메인으로 자동 이전되지 않습니다. 사이트 자료 삭제 시 초기화될 수 있습니다.

사진
화면 표시용 WebP와 업로드 원본 PNG를 함께 포함합니다. 원본은 assets/originals/ 아래에 있습니다. 사진을 크게 열면 PNG 원본이 표시됩니다.

배포 후 확인
배너·사진·음원 URL, 집/지도 버튼, 폰 앱, 사진 확대, 댓글 답장, 찾기 해금, 장부 수습 체크, 모바일 화면을 확인하세요. 최종 배포 주소를 받은 후 그 주소를 클릭형 배너의 목적지로 사용하세요. 이 패키지 생성 자체는 Cloudflare 게시 완료를 뜻하지 않습니다.
